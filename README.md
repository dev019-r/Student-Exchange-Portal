# Student Exchange Information Portal

A web-based information portal designed to help students explore international exchange programs, eligibility guidelines, partner universities, and application steps in one accessible place.

## Key Features
- **Program Overview:** Clear breakdown of student exchange opportunities and academic benefits.
- **Responsive Layout:** Built with clean typography, structured navigation, and mobile-friendly sizing.
- **Information Architecture:** Organized sections for requirements, timelines, and student resources.

## Tech Stack
- **HTML5** – Semantic structure and content layout
- **CSS3** – Custom styling, color palette, and responsive design
